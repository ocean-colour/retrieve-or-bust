API reference
=============

Every public name in ``robust.rt``, generated by ``autodoc`` from the
docstrings in the checkout. One page rather than one page per module, so that
:kbd:`Ctrl-F` finds anything and the right-hand table of contents is the index.

The order below is the pipeline order that ``robust.rt``'s own ``__init__``
docstring uses -- conventions, then the input types, then the data, then the
pieces of the forward model in the order they are composed, then the
comparison baselines and the validation protocol. It is not alphabetical, and
that is deliberate: reading top to bottom is reading the model.

Two conventions hold throughout:

* **The listed members are each module's own ``__all__``**, in source order.
  Every module in the package defines one, grouped by role and marked
  ``# noqa: RUF022`` because the grouping matters more than alphabetical
  order; ``:members:`` with no argument honours it. Private helpers and
  closures are therefore absent by design -- see :doc:`member_policy` for the
  team's governance, and the module source (the ``[source]`` links below) for
  everything else.
* **The signatures are real.** ``autodoc_mock_imports`` is empty (DocQ2): the
  documentation build installs and imports the actual JAX stack, so the type
  annotations shown here -- including ``jaxtyping`` shapes such as
  ``Float[Array, "*batch wave"]`` -- are the ones the interpreter sees, not
  placeholders.

conventions -- the shared choices
---------------------------------

``Rrs`` <-> ``rrs`` (A = 0.52, B = 1.7), the 81-point canonical wavelength
grid, pure-water backscattering ``bb_w(lambda)``, the Raman shift and the one
interpolation routine the whole package uses.

   :members:
   :undoc-members:
   :show-inheritance:


types -- the input pytrees
--------------------------

``IOPs``, ``PhaseParams``, ``Geometry`` and the ``Inelastic`` configuration:
JAX-registered dataclasses, so ``jit`` / ``vmap`` / ``grad`` traverse them and
a gradient with respect to an ``IOPs`` is itself an ``IOPs``.

   :members:
   :undoc-members:
   :show-inheritance:


data.l23 -- the reference batches
---------------------------------

Loisel+2023 HydroLight outputs, loaded through ``ocpy`` into the
``(IOPs, PhaseParams, Geometry, Rrs)`` batches the model is trained and scored
against, plus the seeded held-out splits the acceptance gate needs.

ed -- downwelling irradiance
----------------------------

``Ed(theta_s, lambda)`` at the surface from packaged L23 spectra. Consumed by
the inelastic terms only; the elastic model never calls it.

ztt -- the analytic backbone
----------------------------

The Twardowski & Tonizzo (2018) model transcribed into JAX, with the backward
volume scattering function entering explicitly. Every function names the
paper equation it implements.

The small Flax MLP that predicts the dimensionless residual the backbone

-----------------------

baselines -- what the hybrid must beat
--------------------------------------

Standard Gordon (1988) and O25, in the repo and differentiable so that every
accuracy claim is a comparison computed on identical data rather than a number
quoted from a paper.
